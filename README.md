 DjangoProject

## Описание

Проект DjangoProject _ это проект интернет-магазина. 

## Установка
- [клонируйте репозиторий](https://github.com/albinakazartseva2215/DjangoProject)

- [установите локально Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/download/)

- установите локально Django 
```
pip install django
```

- запустите файл для обработки данных 
```
python manage.py runserver


```

## Использование
1. Перейдите на страницу в GitHub.
2. Создайте новую учетную запись или войдите в существующий.
3. Перенести проект в локальный репозиторий.
4. Запустите файл manage.py для создания web страницы Главная.
